One Draw.define('key', half, (g, f) => { … }): g is the canvas, (0, 0) the centre, half the radius it may fill, f the frame. Plain canvas calls, Math and TAU, Draw.circle / ring / roundRect / glow. The preview redraws as you type; { frames: 4, fps: 8 } as a fourth argument animates it.
