Paste the snippet into Music.THEMES in the game's js/music-themes.js, then set music: 'name' on a boss in BOSSES, or name it maze or dungeon to play in every maze (or maze_level1 … maze_level5 / dungeon_level1 … for one level's mazes, or maze_burrow, maze_cathedral, maze_temple, maze_bigtop for one kind), deck for the saucer deck, complete_level1 … complete_level5 for a short tune played once when that level's boss falls (or complete for every level), dungeon_victory for a tune played once when a dungeon is cleared (or dungeon_victory_level1 …, deck_victory for the saucer deck), perk_shop for the perk shop that follows, or level2 … level5 to play across that level's regions.

HOW IT WORKS

Editing like a spreadsheet: drag a note to move it; drag from an empty cell (or Shift+click, Shift+arrows) to select a block, then drag the block to move it; hold Ctrl while dropping to copy; Alt+arrows nudge it; Ctrl+C / X / V copy, cut, paste at the cursor; DEL clears it; Ctrl+Z undoes; Ctrl+A selects the pattern; Esc drops the selection.

Each row is a 16th note; 32 steps is two bars of 4/4. A track plays its instrument at the note in the row; the note holds for the track's length or until a note off (the pink ===). Drum tracks ignore the pitch except tom and zap. The song is the pattern order looping. In the game the boss music climbs a semitone at 50% and 30% hp and speeds up at 20%; drums stay put.

MUSIC.JS

Songs found in the game's Music.THEMES: tracker songs, and the hand-written boss themes converted into tracks (marked classic; saving one writes a tracker version under the same name, which the game then plays instead). Load brings one into the editor. Save writes the current song into music-themes.js under its name (replacing a song of the same name). Saving needs the dev server (python3 tools/devserver.py); otherwise the snippet goes to the clipboard.
