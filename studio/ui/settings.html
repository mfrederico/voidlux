Every build, chat, fix and review is a one-shot claude -p run in the game's folder on this server, paid by the account the claude CLI is logged into here. There is no API key in the studio. To log in or switch accounts, on the server as ubuntu:

claude setup-token        # long-lived token login (recommended for a server)
claude auth login         # browser login
claude auth status        # what the studio checks

Run settings

Pipeline

The stage prompts (planner, builder, fixer, reviewer, rework) live in studio/agent.py; each game's own rules are its AGENTS.md and the kit's kit/AGENTS.md, which every run reads first. Per-game direction goes in GAME.md (Design tab) or a chat message. The reviewer always runs in a fresh session so it never sees the builder's reasoning.
