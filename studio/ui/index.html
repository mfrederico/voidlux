Anatomy of the forge

◆ The Planner
Reads the brief and writes GAME.md: design, acceptance criteria, ordered tasks. Nothing vague survives into the task list.
● The Builders
Claude Code sessions in the game's own folder, one task at a time, each ending in node --check, a headless soak and a commit.
★ The Reviewer
A fresh session that never saw the build judges every criterion with evidence. Rejected criteria go back as rework, up to two rounds.
∞ The Kit
Centipede's engine pulled out: pooled-voice synth, chip tracker, sprite atlas, touch controls, soak harness. Every game shares it; every editor works on every game.
⚔ Checkpoints
Every run is bracketed by a git tag. Roll back any time; the state before a rollback is a checkpoint too.
♕ Ship
A build with the kit inlined and a version stamp, rsynced to the store folder in one click.
